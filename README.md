# 🚗 Motor Vehicle Collision Analysis

## 🧠 Project Overview

This project was designed to **improve data accessibility and reporting** for safety and transportation initiatives. By analyzing **2.43 million motor vehicle collision records** from U.S. government sources, we delivered a robust data pipeline and compelling visual analytics to drive informed decision-making across stakeholders.

---

## 🎯 Objectives

* Clean, transform, and model large-scale collision data for fast querying and analysis.
* Build a dimensional data warehouse for flexible reporting.
* Provide actionable insights through intuitive and interactive dashboards.
* Support safety initiatives with real-time trend monitoring and hotspot identification.

---

## 🛠️ Tools & Technologies

| Tool         | Purpose                                        |
| ------------ | ---------------------------------------------- |
| **Alteryx**  | Data preparation and large-scale ETL           |
| **Navicat**  | Dimensional data modeling (Star Schema)        |
| **Talend**   | OLAP cube creation for fast aggregation        |
| **Power BI** | Dashboard development for performance tracking |
| **Tableau**  | Visualization of collision patterns and KPIs   |

---

## 🔍 Key Features

* 🧼 **Data Cleansing with Alteryx**: Filtered out anomalies, standardized formats, and enriched datasets with geographic and temporal dimensions.
* 🏗️ **Dimensional Modeling in Navicat**: Designed and implemented star schemas optimized for analytical workloads, improving query performance.
* 🧊 **OLAP Cubes via Talend**: Created cubes to support slice-and-dice analysis on dimensions like location, time, vehicle type, and severity.
* 📊 **Dashboards in Power BI & Tableau**:

  * Trend analysis by date, time, and location
  * Heatmaps of high-risk areas
  * Driver behavior and vehicle-type breakdown
  * Monthly and yearly comparison of incident rates

---

## 📌 Impact

* Enabled **real-time monitoring** of traffic incidents.
* Equipped decision-makers with data to plan **targeted safety campaigns**.
* Reduced reporting effort by automating data refreshes and aggregations.
* Empowered cross-functional teams with self-serve analytics.

---

## 🚀 How to Run the Project

> This is a multi-stage pipeline involving ETL, modeling, and visualization:

1. **Data Preparation**

   * Use Alteryx workflows to ingest and clean raw CSV/JSON/XML files.

2. **Data Modeling**

   * Create star schema models using Navicat for the cleaned data.

3. **OLAP Cube Setup**

   * Generate cubes with Talend for multidimensional analytics.

4. **Dashboard Creation**

   * Connect the cube and modeled data to Tableau/Power BI
   * Design and publish visualizations for stakeholder use
